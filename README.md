# TrackaBite

## Description

TrackaBite is a desktop-based diet tracking application designed to help individuals and communities make healthier dietary decisions. It provides tools to track calorie intake, monitor food consumption, and measure weight status, promoting improved dietary consciousness and nutrition knowledge. The application is accessible to users with limited internet connectivity and ensures data privacy by storing information locally.

### Key Features:
- **Calorie Tracking**: Log and monitor daily calorie consumption.
- **BMI Calculator**: Compute weight classification and health status.
- **Personalized Nutrition**: Receive tailored dietary advice based on age, height, weight, and activity level.
- **Data Privacy**: Local storage ensures full control over personal health information.
- **Educational Use**: Can be integrated into school curriculums or community health programs for nutrition literacy.

---

## Usage

To use TrackaBite, follow these steps:

1. Open the application on your desktop through [trackabite.onrender.com](trackabite.onrender.com).
2. Create an account and log in.
3. Enter your vital statistics (age, height, weight, activity level).
4. Use the BMI calculator and calorie tracker to monitor your diet.
5. Add, delete, or edit food items to manage your meals.
